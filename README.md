# John DuPre: portfolio

Personal site for John DuPre, digital product leader. Live at https://duprejohn.github.io

Built on [Simplefolio](https://github.com/cobiwave/simplefolio) by Jacobo Martínez (MIT). The original template README is in `README-template.md`.

- Edit content in `src/index.html`; images and the resume PDF live in `src/assets/`.
- Every push to `main` rebuilds and publishes the site with GitHub Actions (`.github/workflows/deploy.yml`).
